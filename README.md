# 二丁目町内会 ホームページ

HTML / CSS / JavaScript だけで作られた、町内会向けの静的ホームページです。
VS Codeでフォルダごと開いて、そのまま編集・公開できます。

## フォルダ構成

```
nichome-chonaikai/
├── index.html        … トップページ
├── oshirase.html      … お知らせ一覧ページ
├── gijiroku.html       … 会議議事録一覧ページ
├── post.html           … 投稿・管理ページ（合言葉が必要）
├── css/style.css      … 全ページ共通スタイル
├── js/common.js       … 共通処理（一覧の表示・きらきら演出など）
├── js/auth.js         … 投稿ページ専用の認証・投稿処理
└── assets/            … 子ども・親世代・祖父母世代のイラスト(SVG)
```

## 使い方

1. VS Codeで `nichome-chonaikai` フォルダを開く
2. 拡張機能「Live Server」を入れて `index.html` を右クリック →
   「Open with Live Server」で表示するのがおすすめです
   （`file://` で直接開くことも可能ですが、ブラウザによっては
   投稿データの保存がうまく働かない場合があります）

## お知らせ・議事録の投稿について

- 投稿は **`post.html`（投稿・管理ページ）** から行います。
- はじめに「合言葉」を聞かれます。役員など許可された方だけが
  投稿できるようにするための簡易的なロックです。
- 合言葉は `js/auth.js` の中にある次の行で変更できます。

  ```js
  const ADMIN_PASSWORD = "nichome2024";
  ```

  ここを町内会内で決めた合言葉に書き換えてご利用ください。

- 投稿されたお知らせ・議事録は、写真（JPGなど）と説明文とあわせて
  ブラウザの中（localStorage）に保存され、トップページ・お知らせページ・
  議事録ページに自動で反映されます。
- 投稿の削除も `post.html` の「投稿の管理」から行えます。

### ⚠️ ご注意（重要）

この合言葉によるロックは、あくまで「誰でも書き込めないようにする」ための
簡易的な仕組みです。ブラウザの開発者ツールなどで解析されると突破される
可能性があるため、個人情報など重要なデータの管理には使わないでください。

また、投稿データは各パソコン・各ブラウザの中に保存される仕組みです。
そのため、

- 投稿した本人のパソコン・ブラウザでは反映された内容が見える
- 別のパソコンや別の人のブラウザでは、その投稿は表示されない

という点にご注意ください。町内会の全員に同じ内容を見せたい場合は、
将来的にサーバー（レンタルサーバーや無料のクラウドサービスなど）と
組み合わせた仕組みへの発展をおすすめします。ご希望があれば、その
仕組み（データベース連携など）の追加もお手伝いできます。

## デザインについて

- 回覧板・コルクボードをイメージした掲示板デザインで、地域の温かみを表現しています。
- 子ども／お父さん・お母さん世代／おじいちゃん・おばあちゃん世代の
  3世代のイラストをトップページに配置し、地域活性化のイメージを表現しています。
- 背景にはやさしい「きらきら」のアニメーションを配置しています
  （`prefers-reduced-motion` 設定時は自動的に控えめになります）。

## 色・フォントを変えたい場合

`css/style.css` の一番上にある `:root { ... }` 部分の色（`--sun` や
`--persimmon` など）や、`--font-display` / `--font-body` を書き換えると、
サイト全体の配色・フォントをまとめて変更できます。
