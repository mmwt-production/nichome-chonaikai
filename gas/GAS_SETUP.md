# お問い合わせフォーム × Googleスプレッドシート 連携セットアップ手順

`contact.html`（お問い合わせページ）に届いた内容を、Googleスプレッドシートに自動保存し、
1件ごとにA4サイズにぴったり収まる専用シートを作成する仕組みのセットアップ手順です。
無料のGoogleアカウントと「Google Apps Script（GAS）」だけで動きます。

---

## 全体の流れ

1. Googleスプレッドシートを新規作成する
2. 「テンプレート」シートを作り、A4縦にぴったり収まるレイアウトを作る
3. Apps Scriptに `Code.gs` の内容を貼り付ける
4. Webアプリとして公開し、URLを取得する
5. `js/contact.js` にそのURLを設定する

---

## 手順1：スプレッドシートを新規作成

1. Googleドライブで「新規」→「Googleスプレッドシート」を作成
2. わかりやすい名前を付けます（例：「二丁目町内会 お問い合わせ管理」）

## 手順2：「テンプレート」シートを作る

1. シート下部の「＋」でシートを追加し、シート名を **テンプレート** に変更します
   （名前は１文字も違わずこの通りにしてください）
2. このシートに、会議で配る紙をイメージしたレイアウトを自由に作ります。
   例えば以下のように配置します。

   ```
   A1: 二丁目町内会　お問い合わせ内容
   A3: 受付日時　　B3: {{受付日時}}
   A4: お名前　　　B4: {{お名前}}
   A5: ご連絡先　　B5: {{連絡先}}
   A6: 件名　　　　B6: {{件名}}
   A8: お問い合わせ内容
   A9: {{内容}}    （このセルを大きめにして、内容が入るようにする）
   ```

   `{{受付日時}}` `{{お名前}}` `{{連絡先}}` `{{件名}}` `{{内容}}` の部分は
   そのままの文字列で入力してください。あとでスクリプトが自動的に実際の内容に
   置き換えます。文字サイズを大きくしたり、罫線・背景色を付けたりして、
   70代の方にも見やすいレイアウトに仕上げてください。

3. **A4縦にぴったり収める設定**
   - メニューの「ファイル」→「印刷」を開きます
   - 用紙サイズ：A4／ページの向き：縦 を選択
   - 「次のページに合わせて拡大縮小」→「幅に合わせる」または「1ページに収める」を選択
   - 余白もお好みで調整し、プレビューで綺麗に収まることを確認します
   - 確認できたら、右上の「×」または「印刷を終了」で閉じます
     （この設定はシートに保存され、後で複製したシートにも自動的に引き継がれます）

## 手順3：Apps Scriptにコードを貼り付け

1. スプレッドシートのメニューから「拡張機能」→「Apps Script」を開きます
2. デフォルトで開かれる `コード.gs`（または `Code.gs`）の中身をすべて削除し、
   同梱の `gas/Code.gs` の内容を丸ごと貼り付けます
3. コード上部の次の行を、実際のスプレッドシートのIDに書き換えます。

   ```js
   const SHEET_ID = "ここにスプレッドシートのIDを入力";
   ```

   スプレッドシートのIDは、ブラウザのURLの中にあります。

   ```
   https://docs.google.com/spreadsheets/d/【この部分がID】/edit
   ```

4. 上部の「保存」（フロッピーディスクのアイコン）を押します

## 手順4：Webアプリとして公開する

1. 右上の「デプロイ」→「新しいデプロイ」を選択
2. 歯車アイコン（種類の選択）→「ウェブアプリ」を選択
3. 次の設定にします。
   - 説明：任意（例：お問い合わせフォーム連携）
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
4. 「デプロイ」を押すと、初回はGoogleアカウントへのアクセス許可を求められるので、
   画面の指示に沿って許可します
   （「このアプリは確認されていません」という警告が出た場合は、
   「詳細」→「（プロジェクト名）に移動」と進んで許可してください。
   自分で作成したスクリプトなので問題ありません）
5. 発行された「ウェブアプリのURL」をコピーします
   （`https://script.google.com/macros/s/......../exec` のような形式です）

## 手順5：サイト側にURLを設定する

1. `js/contact.js` を開きます
2. 次の行を、手順4でコピーしたURLに書き換えます。

   ```js
   const GAS_WEB_APP_URL = "ここにGASのWebアプリURLを貼り付けてください";
   ```

3. 保存して、`contact.html` をブラウザで開き、テスト送信してみます
4. スプレッドシートに戻り、
   - 「問い合わせ一覧」シートに1行追加されていること
   - 「問い合わせ_（日時）」という新しいシートが作られ、
     テンプレートの内容が実際の入力内容に置き換わっていること
   - そのシートを印刷プレビューすると、A4縦にきれいに収まっていること

   をそれぞれ確認してください。

---

## コードを修正した場合の注意

`gas/Code.gs` の内容を編集したときは、Apps Scriptエディタ側でも保存したうえで、
**「デプロイ」→「デプロイを管理」→ 編集(鉛筆アイコン)→ 新しいバージョン→ デプロイ**
の手順で再デプロイしないと、変更がWebアプリ側に反映されません。
（URLを変えずに中身だけ更新する場合の操作です）

## うまく動かないときは

- 「テンプレート」という名前のシートが完全に一致しているか確認してください
  （全角/半角のずれなどでも認識されません）
- Apps Scriptの画面上部「実行数」や「実行ログ」から、エラーの詳細を確認できます
- デプロイ時のアクセス設定が「全員」になっているか確認してください
  （「自分のみ」だと、サイトからの送信が拒否されます）
